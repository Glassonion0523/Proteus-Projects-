# ☀️ Solar Panel Voltage Measurement Using Arduino

## About This Project

This project measures the output voltage of a solar panel using an Arduino Uno and displays the measured value on a 16×2 LCD.

A voltage divider circuit is used to safely scale the solar panel voltage to a range suitable for the Arduino's analog input. The Arduino continuously reads the voltage, performs the necessary calculations, and displays the real-time voltage value on the LCD.

The project was developed to improve my understanding of analog sensing, voltage measurement techniques, and Arduino-based monitoring systems.
