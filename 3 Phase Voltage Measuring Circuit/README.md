# ⚡ Three-Phase Voltage Measurement System Using Arduino

## About This Project

This project is an Arduino-based three-phase voltage monitoring system developed and simulated in Proteus.

The system measures the voltages of three AC phases independently and displays the measured values on a 16×2 LCD. Voltage transformers and signal conditioning circuits are used to safely reduce the input voltages to levels suitable for the Arduino's analog inputs.

This project was developed to improve my understanding of electrical measurement systems, three-phase power distribution, signal conditioning, and embedded system applications.

## Working Principle

The three AC phase voltages are first stepped down using transformers to obtain safe low-voltage signals.

The output from each transformer is conditioned using resistor divider networks and filtering components before being connected to the Arduino's analog input pins.

The Arduino continuously reads the analog voltages, processes the measured values, and calculates the corresponding phase voltages.

The measured voltages are then displayed on the 16×2 LCD, allowing real-time monitoring of all three phases.
