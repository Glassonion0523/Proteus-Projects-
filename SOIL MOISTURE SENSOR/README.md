# Soil Moisture Monitoring System Using Arduino

## Project Overview

This project is an Arduino-based soil moisture monitoring system designed and simulated in Proteus. It uses a soil moisture sensor to measure the water content present in the soil and displays the moisture percentage on a 16×2 LCD screen.

The project helps in understanding how environmental parameters can be monitored using sensors and how sensor data can be processed and displayed using Arduino. Such systems are widely used in smart agriculture and automated irrigation applications.

## Components Used

* Arduino Uno
* Soil Moisture Sensor Module
* 16×2 LCD Display
* Potentiometer (for simulation and calibration)
* Capacitor
* Inductor
* Proteus 8 Professional

## Features

* Measures soil moisture level in real time.
* Displays moisture percentage on a 16×2 LCD.
* Provides continuous monitoring of soil conditions.
* Helps determine when watering is required.
* Simulated completely in Proteus.

## How It Works

The soil moisture sensor detects the amount of moisture present in the soil by measuring changes in electrical conductivity between its probes. The sensor generates an analog signal corresponding to the moisture level.

The Arduino reads this analog value through one of its analog input pins and converts it into a moisture percentage. The calculated value is then displayed on the LCD screen, allowing the user to monitor soil conditions easily.

This system can be used as the foundation for automated irrigation and smart farming projects.
